# Shapes Requirements

Shapes represent 2D objects in the engine.

## Circle
- Position (Vector2)
- Radius (float)

Supports:
- Getting bounds
- Rendering to screen

## Rectangle
- Position (Vector2)
- Width (float)
- Height (float)

Supports:
- Getting bounds
- Rendering to screen

## Triangle
- Position (Vector2)
- Three Points (Vector2 array)
- Size/Scale (float)

Supports:
- Getting bounds
- Rendering to screen

## Line
- Start Point (Vector2)
- End Point (Vector2)
- Thickness (float)

Supports:
- Getting length
- Rendering to screen

## Dot
- Position (Vector2)
- Size (float)

Supports:
- Rendering to screen
